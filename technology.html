AI COMPUTE

Choose compute for your actual workload.

Cloud GPUs can accelerate person detection and other computer vision inference tasks. CPU and decoder capacity are equally important for maintaining the overall video pipeline.

  • Plan for camera count, resolution and model complexity.
  • Distinguish source frame rate from analysed inference FPS.
  • Benchmark throughput, model quality and alert latency together.
  • Monitor GPU memory, CPU load and processing backlogs.

OBSERVABILITY

Measure what the pipeline actually delivers.

The following should be captured from deployed workloads and labelled clearly by environment.

Processing FPS

Analysed frames per second, per stream and overall.

Model quality

Task-specific precision, recall and counting error.

Alert latency

Event-to-notification delay, including p95 where relevant.

Storage consumption

Retained video, event data, archives and backups.

PRIVACY BY DESIGN

Responsible video analytics is part of the architecture.

Retail footage can contain identifiable individuals. Design choices should address the purpose of processing, approved access, data transfer, retention and human review before a deployment goes live.

  • Collect only the data needed for defined analytics.
  • Restrict camera credentials and dashboard permissions.
  • Specify encryption, retention and deletion controls.
  • Use human review for alerts that could affect people.

Good to know

Frequently asked questions

Clear answers before you plan your video analytics project.

Does each camera need a dedicated GPU?

No. One GPU may process several streams, but capacity must be established through benchmarks of the real pipeline.

How much storage is needed?

It depends on bitrate, number of cameras, continuous versus event-only recording, retention and backup policies.

What is processing FPS?

The number of video frames the analytics pipeline processes each second. It may differ from the camera source frame rate.

What should count as model accuracy?

There is no one universal metric. Use precision, recall and task-specific measures such as counting error on representative labelled footage.

Can the infrastructure scale?

The architecture can be designed to add processing resources, but actual scaling behaviour must be tested with network, decode, inference and storage demands.
